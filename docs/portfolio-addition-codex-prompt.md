## 掲載する作品情報

- 作品名: 売上管理システム
- カテゴリ: 業務システム
- 概要: 日々の取引を整数円で正確に記録し、店舗・担当者・商品・顧客・支払方法の KPI と分析へ変換する Web 業務システム
- 想定ユーザー: 小売、サロン、美容室、飲食、スクール、営業会社、サービス業、EC、フリーランス、小規模〜中規模企業
- 解決する課題:
  - 最大 2 明細、割引、複数税率、取消、返金を含む売上を一貫した規則で記録する
  - 分散した取引・顧客・商品・担当者・店舗・目標を一元化する
  - 登録データを前期間比、目標差、粗利、顧客行動へ変換する
  - テナント・店舗・担当範囲を越えるアクセスと取消後の改変を防ぐ
  - CSV の列・参照・金額エラーを登録前に発見する
- 対応プラットフォーム: Web。PC、タブレット、スマートフォン対応
- 開発状況: ローカル実装済み。公開・デプロイ状況は実行時に再確認する

### 実装済みの主な機能

- Firebase Authentication のメール／パスワード認証、新規組織登録、ログアウト、パスワード再設定
- 登録不要で閲覧者ごとのブラウザ内に保存するデモ、4 ロール切替、初期データ復元
- 最大 2 明細の売上登録・編集、整数円計算、理由付き取消、全額／一部返金、複製、印刷、更新履歴
- 取引番号・顧客・商品・担当者検索と、期間・店舗・担当者・商品・支払方法・金額・状態の複合絞り込み
- 今日／7日／30日／今月／先月／今年／前年／任意期間と連動する売上・件数・平均客単価・目標ペースの KPI とグラフ
- 商品・サービス、顧客、担当者、店舗、月間／年間目標の管理
- 担当者、商品・カテゴリ、顧客、店舗、支払方法の売上分析
- 日報・月報とブラウザ印刷
- 売上、顧客、商品、担当者別、店舗別 CSV 出力
- 売上、商品、顧客 CSV の必須列・金額・参照、既存／入力内重複、売上 2 明細上限、商品原価の検証、エラー行表示、登録前プレビュー
- 管理者、マネージャー、一般、閲覧のみの権限モデル
- `organizationId` / `locationId` によるマルチテナント Firestore、Security Rules、監査ログ
- 194 件の売上、291 件の明細を含む合計 947 Firestore ドキュメントの決定的な日本語架空 seed

### 工夫したポイント

- 金額を整数円、税率を basis points で保持し、各明細で税を切り捨てる
- 商品粗利率は税抜認識売上を分母にし、返金配賦の端数を最後の明細へ集約して集計合計を完全一致させる
- 確定・未確定・取消・全額返金・一部返金で純売上の認識規則を統一する
- 登録、一覧、ダッシュボード、分析、目標、レポートが同じ集計関数を使用する
- 対象ドキュメントと監査ログを同一 Firestore バッチへ束縛する
- Rules で数量 × 単価、明細別切捨て税、親合計、更新前時刻の CAS、返金累計の単調増加を検証する
- デモでは Firebase を初期化せず、共有データを破壊しない
- Apple Design の目的・主体性・馴染み・単純さ・細部を、数値比較優先の業務 UI へ適用する
- 44px 操作領域、フォーカス表示、ARIA、色だけに依存しない状態、reduced motion / transparency / contrast へ配慮する
