# CSV 入出力仕様

この文書は `src/lib/sales/csv.ts` と `src/features/csv/csv-center.tsx` の実装に基づきます。

## 共通形式

### エクスポート

- 文字コード: UTF-8 BOM 付き
- 改行: CRLF
- 区切り: カンマ
- すべてのセルをダブルクォートで囲む
- セル内の `"` は `""` にエスケープ
- 先頭の空白を除いて `=`、`+`、`-`、`@`、タブ、CR で始まる文字列は、先頭へアポストロフィを付けて表計算ソフトの数式実行を防ぐ

### インポート

- UTF-8 の BOM あり／なしに対応
- 1 行目をヘッダーとして扱う
- カンマ、エスケープ済み引用符、セル内改行を扱う RFC 4180 相当のパーサー
- 重複ヘッダー、必須列不足、閉じていない引用符はファイル全体エラー
- 各行の列数、必須値、型、金額、参照を検証し、行番号ごとにエラーを表示
- 空行は無視
- 1 行でもエラーがある場合は取込ボタンを無効化
- 取込前に先頭 8 行を表示。エラー一覧は先頭 30 行を画面表示
- 売上の取引番号、商品の商品コード、顧客のメール／電話（連絡先なしの場合は氏名）を、既存データと CSV 内の両方で重複検知
- 雛形は CSV 画面からダウンロード可能

## エクスポート

### 売上一覧

1 取引を 1 行で出力します。

| 順番 | ヘッダー | 内容 |
| ---: | --- | --- |
| 1 | 取引番号 | 取引番号 |
| 2 | 売上日時 | ISO 日時 |
| 3 | 顧客名 | 取引時点の顧客名 |
| 4 | 店舗ID | `locationId` |
| 5 | 担当者名 | 取引時点の担当者名 |
| 6 | 商品・サービス | 明細名を ` / ` で連結 |
| 7 | 数量合計 | 全明細の数量合計 |
| 8 | 小計 | 整数円 |
| 9 | 割引 | 整数円 |
| 10 | 消費税 | 整数円 |
| 11 | 合計 | 税込整数円 |
| 12 | 返金額 | 返金累計 |
| 13 | 純売上 | ステータス別認識後の金額 |
| 14 | 支払方法 | 表示名 |
| 15 | ステータス | 確定／未確定／取消／返金／一部返金 |
| 16 | 登録日時 | ISO 日時 |
| 17 | メモ | 取引メモ |

売上一覧画面から出力すると、その時点の検索・絞り込み結果だけが対象です。CSV センターから出力すると、Repository が読み込んだ売上一覧全体が対象です。

### 顧客一覧

```text
顧客ID, 顧客名, 顧客種別, 電話番号, メールアドレス,
登録日, 最終購入日, 購入回数, 累計売上, 平均購入金額, タグ
```

顧客種別は `個人` または `法人`、タグは ` / ` で連結します。

### 商品・サービス一覧

```text
商品ID, 商品コード, 商品・サービス名, 種別, カテゴリID, 説明,
販売価格, 原価, 税率(%), 状態, 登録日, 更新日
```

種別は `商品` または `サービス`、状態は `有効` または `無効` です。税率は basis points を百分率へ戻して出力します。

### 担当者別売上／店舗別売上

```text
担当者ID または 店舗ID,
担当者 または 店舗,
順位, 純売上, 取引件数, 平均客単価, 売上構成比(%),
売上目標, 目標差額, 達成率(%), 前期間売上, 前期間比(%)
```

CSV センターでは当月データから分析した結果を出力します。

## 売上インポート

### 形式

1 明細を 1 行で記載します。同じ取引番号の最大 2 行は 1 取引の複数明細へまとめます。3 行以上の同一取引は、該当する全行をプレビューエラーにします。

| ヘッダー | 必須列 | 値の条件 |
| --- | :---: | --- |
| 取引番号 | ✓ | 空文字不可。同一取引のグループキー |
| 売上日時 | ✓ | JavaScript で解釈可能な日時。保存時に ISO へ正規化 |
| 顧客ID | ✓ | 現在読み込まれている顧客 ID と一致 |
| 店舗ID | ✓ | 現在読み込まれている店舗 ID と一致 |
| 担当者ID | ✓ | 現在読み込まれている担当者 ID と一致 |
| 商品ID | ✓ | 現在読み込まれている商品・サービス ID と一致 |
| 数量 | ✓ | 1 以上の安全な整数 |
| 単価 | ✓ | 0 円以上の安全な整数 |
| 明細割引 | ✓ | 0 円以上、小計以下の安全な整数 |
| 税率(%) | ✓ | 0〜100。basis points へ正確に変換できる値 |
| 支払方法ID | ✓ | 現在読み込まれている支払方法 ID と一致 |
| 売上区分 | ✓ | 下表の受入値 |
| ステータス | ✓ | 下表の受入値 |
| メモ | 任意 | ヘッダーがなくても可 |

### 売上区分の受入値

| 入力 | 保存値 |
| --- | --- |
| `retail` / `店頭` | `retail` |
| `service` / `サービス` | `service` |
| `subscription` / `定期` | `subscription` |
| `other` / `その他` | `other` |

### ステータスの受入値

| 入力 | 保存値 |
| --- | --- |
| `confirmed` / `確定` | `confirmed` |
| `pending` / `未確定` | `pending` |

CSV プレビューで受け入れるのはこの 2 値だけです。`cancelled` / `取消`、`refunded` / `返金`、`partially_refunded` / `一部返金` は行別エラーになり、取込できません。取消・返金は元取引を登録後、専用操作から監査履歴付きで記録します。

### 同一取引番号の整合性

同じ取引番号では、次の値がすべて一致する必要があります。

- 売上日時
- 顧客 ID
- 店舗 ID
- 担当者 ID
- 支払方法 ID
- 売上区分
- ステータス

一致しない行は行別エラーになります。商品 ID、数量、単価、割引、税率は明細ごとに異なって構いません。

取引番号が既存売上と一致する場合は、該当行をエラーにします。同一 CSV 内では同じ取引番号を複数明細のグループキーとして使用できますが、全列が同じ明細行を重複させると、最初の行を含めてエラーになります。

### 金額計算

CSV は税額・小計・合計を受け取りません。各明細を次の式で再計算します。

```text
小計 = 数量 × 単価
課税対象 = 小計 - 明細割引
税 = floor(課税対象 × 税率 / 100)
明細合計 = 課税対象 + 税
```

税の内部表現は basis points であり、実装式は `floor(課税対象 × taxRateBps / 10,000)` です。

### ID と監査

- 取引 ID は取込時に UUID を生成
- 取引番号は CSV の値を保持
- 明細 ID は取引 ID と行順から生成
- 商品・顧客・担当者・店舗・支払方法の表示名と原価は、登録済みマスタから取得
- 作成者・更新者はログインユーザー
- 取込結果は監査ログに記録
- Firestore では 4 取引ごとに、売上 4 件 + 監査ログ 4 件を 1 バッチで commit

1 回の commit は原子的です。ただし CSV ファイル全体を 1 トランザクションにはしていないため、後続 commit が失敗しても、成功済みの先行 commit は自動ロールバックされません。再実行時は既存取引番号の重複検知で二重登録を防ぎます。

## 商品・サービスインポート

| ヘッダー | 必須列 | 値の条件 |
| --- | :---: | --- |
| 商品コード | ✓ | 空文字不可 |
| 商品・サービス名 | ✓ | 空文字不可 |
| 種別 | ✓ | `商品` / `product` / `サービス` / `service` |
| カテゴリID | ✓ | 空文字不可 |
| 販売価格 | ✓ | 0 円以上の安全な整数 |
| 原価 | ✓ | 0 円以上の安全な整数 |
| 税率(%) | ✓ | 0〜100 |
| 状態 | ✓ | `有効` / `true` / `1` / `無効` / `false` / `0` |
| 説明 | 任意 | ヘッダーがなくても可 |

ID は、商品コードを英小文字・ハイフンへ正規化した文字列とランダム接尾辞から生成します。商品コードは保存時に大文字化されます。

CSV パーサーは `原価 <= 販売価格` を登録前に検証し、商品コードは既存データと CSV 内の両方で重複検知します。現在は `カテゴリID` の存在確認を行わないため、事前に正しい値を雛形へ設定してください。Cloud Firestore モードでは Rules も `原価 <= 販売価格` を検証します。

## 顧客インポート

| ヘッダー | 必須列 | 値の条件 |
| --- | :---: | --- |
| 顧客名 | ✓ | 値も必須 |
| 顧客種別 | ✓ | `個人` / `individual` / `法人` / `corporate` |
| 電話番号 | ✓ | 列は必須、値は空でも可 |
| メールアドレス | ✓ | 列は必須、値は空でも可。入力時は形式検証 |
| タグ | 任意 | `|`、`/`、`／` 区切り |

ID は UUID、登録日時は取込時刻、購入回数・累計売上・平均購入金額は 0、有効状態は `true` で登録します。

メールアドレスと電話番号は、既存データと CSV 内の両方で重複検知します。メール・電話がどちらも空の場合は、顧客名の重複を検知します。

## エクスポートとインポートの非対称性

売上一覧エクスポートは分析・保管用の「1 取引 1 行」、売上インポートは複数明細を再構成する「1 明細 1 行」です。このため、売上一覧エクスポートをそのまま売上インポートへ渡すことはできません。

商品・顧客も、エクスポートには ID や集計値などの読取専用列が含まれ、インポート必須列とは一致しません。再取込を行う場合は画面から雛形を取得し、必要列を移してください。

## エラー例

```text
必須列がありません: 顧客ID、店舗ID
行 4: 顧客IDが登録済み顧客と一致しません。
行 7: 明細割引は小計以下で指定してください。
行 9: 同じ取引番号の売上日時・顧客・店舗・担当者・支払方法・区分・状態が一致しません。
行 11: 同じ取引番号の明細は2件以下にしてください。
行 13: 原価は販売価格以下で入力してください。
CSVの引用符が閉じられていません。
```

